# 調査レポートの要点と出典

元資料：「ゲームの爽快感・達成感 調査」（調査日 2026-11-26）。開発者インタビュー・講演紹介・公式サイト・学術論文紹介を、日本語と英語のソースでウェブ確認したもの。**プレイ検証は含まない**。
「事実」は出典に書かれている発言・研究結果、「応用」はレポートが導いた転用案。この2つを混同しないこと。

## 概念

- **game feel**（Steve Swink 2009）：「シミュレートされた空間における仮想オブジェクトのリアルタイム制御であり、その相互作用が polish によって強調されたもの」。要素は、リアルタイム制御・模擬された空間・polish の3つ。→ 応用：実装は「制御 → 空間 → 演出」の順に進める。
- **juice**（Jonasson & Purho「Juice it or lose it」GDC Europe 2012）：「最小の入力に対する最大の出力」。ブロック崩しのルールを変えずに、tween・squash & stretch・シェイク・音だけで別物にしてみせた。
- **The Art of Screenshake**（Jan Willem Nijman, INDIGO 2013）：約30の工夫を1つずつ積む実演。画面シェイク、ヒットストップ（sleep）、マズルフラッシュ、反動、ノックバック、ヒットフラッシュ、死体の残留（permanence）、カメラの lerp とキック、効果音のピッチのランダム化など（二次整理による）。
- **手ごたえ（tegotae）**（任天堂）：「手触り感が大事」「つねに新しいおもちゃであるべき」。Bill Trinen は tegotae を "hand response" と説明した。宮本茂氏は「重さ（weight）」と「応答（response）」を挙げ、壁の前では壁があるように反応しなければ断絶が生じると語った。→ 応用：「抵抗 → 解放」の波形を作る。
- **リスクとリターン**（桜井政博）：リスクとリターンはかなり近くに、適切な大きさで置き、大きさはほぼ比例させる。マリオの踏みつけは、リスクが最大になった地点でリターンが生じる。カービィは意図的な低リスク設計。
- **ヒットストップ**（桜井政博、二次要約経由）：当たった瞬間にほんの一瞬止める。ジャンルを問わず入れてよい。ボス撃破時の大きな止めは「ボスストップ」と呼ばれる。段階は、そのまま／止め／止め＋振動／止め＋振動＋スロー。
- **フロー**（Csikszentmihalyi、Schell 経由の二次整理）：課題と技能が釣り合ったときに没入が生じる。条件は、明確な目標・測定できる進捗・即時で曖昧でないフィードバック・制御できる感覚。
- **SDT / PENS**（Ryan, Rigby & Przybylski 2006）：自律性・有能感・関係性の3つの欲求が、楽しさと将来のプレイ意向を予測する。高める要因は、習得しやすい操作・明確で一貫したフィードバック・目標や戦略の選択・協力的な交流。
- **juice の逆U字**（Kao 2020, Entertainment Computing, DOI: 10.1016/j.entcom.2020.100359、二次要約経由）：演出量の4条件のうち、Medium と High が、プレイ時間・体験・内発的動機・成績のすべてで None と Extreme を上回った。

## 「面倒な作業がゲームだと楽しくなる」理由（仮説）

- **A** 面倒さは作業本体ではなく、その前後に付いている。ゲーム化とは、面倒の除去ではなく**快感の核の抽出**である（Rigden 氏：洗う過程は楽しいが、準備と後片付けが楽しさを奪った）。
- **B** ビフォー／アフターのコントラストが強いほど爽快。
- **C** 進捗は二重に見せる：空間的な進捗（塗り替わった面積）と数値的な進捗（%・残量）。
- **D** 完了の区切りが小さいほど、達成感は頻繁になる。
- **E** 低リスクと自分のペースが心地よさを作る。ただしリスクがゼロだとリターンも小さくなりやすいので、効率・美しさ・自己ベストを「自分への課題」として置く。
- **F** 現実の作業にないもの：出力の増幅、到達できる「100%」、世界が仕事を覚えている（permanence）。

## 草刈りゲームへの応用例（レポートの提案）

コアループ：移動 → 草に触れる（抵抗） → 刈れる（解放＋音＋草片） → 地面の色が変わる（痕跡） → 区画が完了する（DING＋%上昇） → 道具が成長する → もっと密な／広い場所へ。

- 未刈りは濃い緑で背が高く揺れる、刈り済みは明るい黄緑で平坦。境界に1〜2pxの明るいエッジを付ける。
- 全体%は常に表示し、区画が完了したら跳ねさせて DING を鳴らす。最後の数本は残り草のハイライトで支援する。
- コンボで移動速度と刈り幅が少し上がる。切れても罰なし。刈り音は音階を上る。
- 音は3層：刈り音（ピッチランダム）、成長・コンボ音（音階上昇）、完了音（区画完了のみ）。
- ヒットストップは区画が100%になった瞬間（約100ms＋フラッシュ）と、特別な草を刈ったときだけ。
- 画面シェイクは原則使わない。代わりに刈り機の微振動と、一瞬のノックバックで重量感を出す。
- 道具：鎌 → 草刈り機 → 乗用（縞が作れる）。成長ごとに新しい気持ちよさを1つ足す。
- 縞模様は「美しさ」の任意評価にする。往復の方向で明度をわずかに変える。
- 制限時間はデフォルトで入れず、別モードにする。時間切れでも刈った分は残す。

## 限界

- Unpacking / House Flipper / Death Stranding は、開発者の一次発言を確認できていない（構造の類似のみ）。
- 桜井氏のヒットストップ論と Kao (2020) は二次要約に基づく。フロー理論のゲームへの適用は Schell 経由。
- モバイルの草刈りゲームは、ストアの文言のみ。
- ms などの数値は一般的な範囲の目安。
