# 001 坊主メーカー

- **ジャンル**: アクション
- **制作日**: 2026-11-26（テーマずらし改修も同日）
- **操作**: WASD / 矢印キー、スマホはドラッグ

## テーマ・狙い
もとは「草刈りゲーム」。操作（移動して面をなぞって消す）はそのままに、テーマだけをずらして独自性を出す実験作。
フィールドは上から見たお客さんの頭、草は髪、芝刈り機はバリカン。刈った後はツルツル光る頭皮が痕跡として残る。

## 学んだこと
- テーマずらしの条件は「一言で言える前提」「テーマの動詞＝操作の動詞」「真面目な実行」の3点（テーマずらし調査より）
- 音（バリカンのジー音）・痕跡（頭皮の光沢）・完了の意味（仕上がり）が全部テーマ固有になると、色替えではなくなる
- 12区画は頭の部位（後頭部・頭頂部・前髪・もみあげ等）になり、完了表示は「○○ 仕上がり！」
- 障害物の岩はほくろに、ボーナスは白髪（20点）とアホ毛（30点）に、成長はバリカン幅アップに読み替えた
