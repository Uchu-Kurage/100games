# 001 草刈りゲーム

- **ジャンル**: アクション
- **制作日**: 2026-11-26
- **操作**: WASD / 矢印キー、スマホはドラッグ

## テーマ・狙い
60秒で野原の草を刈りまくるゲーム。爽快感・達成感の調査で得た知見（即時フィードバック、痕跡、完了音）を反映した改修版。
プロジェクトのコンセプトは「5歳児でも遊べるゲームを100つくる」（2026-11-26に変更）。

## 学んだこと
- フィールドを12区画に分け、区画を刈り切るたびに完了音（DING）とボーナスで「小さな完了の連鎖」を作る
- 刈った痕跡のコントラスト（濃い緑→明るい黄緑）を最大化すると達成感が跳ね上がる
- コンボで効果音の音階が上がる増幅、芝刈り機の成長、制限時間なしののんびりモード

## 反省・次にやりたいこと
- 5歳児でも遊べるという新コンセプトに合わせ、操作や難しさの見直しは今後の課題
- このゲームは単一HTMLファイル構成で、共通モジュール（shared/）にはまだ切り出していない

## 5歳児向け改良（2026-11-26、子ども向けゲーム調査に基づく）
- 標準モードを制限時間なしに変更（60秒は任意モードとして残置）。失敗・罰なしは維持
- 区画完了ごとに、完了区画数と刈った本数を大きな数字で数え上げる演出を追加（数への関心への接続）
- スタート画面はアニメーションで遊び方を見せる絵中心の案内にし、ボタンを大型化
- 約7秒無操作で近くの未刈りエリアが光る足場かけヒント、過程を褒める表示と星・花のごほうび演出を追加

## ゲーム作りの工夫（2026-11-26にゲーム画面からREADMEへ移行）
※教育的観点は「保護者向け」としてゲーム画面下部に残している。ここには制作ノート（工夫）だけを置く。
- 気持ちよさの工夫: 入力した瞬間に音・動き・光が返る即時フィードバック／刈った痕跡が色で残る可視的変化（濃い緑→明るい黄緑、縞模様、刈りたての光る縁）／12区画の小さな完了の連鎖（完了音DING＋ボーナス＋一瞬のヒットストップ）／コンボで刈り音の音階が上がる増幅／密な草では重く刈れた場所では軽い「抵抗→解放」／刈るほど芝刈り機が育つ成長の可視化／80%超で残りが光る取り残し支援
- 画面シェイクや過剰な演出は、調査のアンチパターン（盛りすぎは逆効果）に沿って最小限にしている
- 5歳向けの工夫: 制限時間なしを標準に／区画完了ごとに数を大きく数え上げる／約7秒無操作で近くの未刈りエリアが光るヒント／過程を褒める表示とごほうび演出／遊び方はアニメーションで見せる
- 文字のルール（プロジェクト標準）: ゲーム画面の文字は最小限・ひらがなのみ。タイトルは「くさかり」、HUDは絵文字＋大きな数字

## 二層設計の見直し（2026-11-27）
- ユーザーの方針「教育的観点もありつつ、大人でも爽快感・達成感を味わえるもの」を受け、子ども層（のんびりモード・数え上げ・ヒント・罰なし）は無変更のまま、大人層として「60びょう」モードをスコア制に強化した
- 区画を100%刈り切ると「とりのこし なし！」ボーナス（+150点〜）と金色の専用演出。通常の区画完了（95%）とは判定を分離し、区画の最後の1本を刈ったときだけ100%が確定する作りにした
- 終了時に星1〜3ランクとセッション内ベストを表示（ベストはメモリ保持のみ、永続化なし）
