# 001 草刈りゲーム

- **ジャンル**: アクション
- **制作日**: 2026-11-26
- **操作**: WASD / 矢印キー、スマホはドラッグ

## テーマ・狙い
現実では面倒な草刈りが、やり始めると爽快で達成感があるのはなぜかを言語化し、ゲームに取り入れる。
爽快感・達成感の調査（即時フィードバック、痕跡の可視化、小さな完了の連鎖など）を反映した。

## 学んだこと
- 野原を12区画に分け、区画を刈り切るたびに完了音（DING）とボーナスを出す「小さな完了の連鎖」
- 未刈り＝濃い緑／刈り済み＝明るい黄緑のコントラストと、縞模様・刈り草の残留による「痕跡」の見せ方
- コンボで効果音のピッチを上げる即時フィードバック、密な草での抵抗→解放の手触り
- 制限時間なしの「のんびりモード」で、自分のペース（自律性）も選べるようにした

## 反省・次にやりたいこと
- 気持ちよさはプレイ感覚の調整が要るので、実際に遊んだ感想をもとに音量や抵抗感を詰めたい
- このゲームは単一HTMLファイル構成で、共通モジュール（shared/）にはまだ切り出していない
