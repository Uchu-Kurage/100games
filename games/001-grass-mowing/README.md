# 001 草刈りゲーム

- **ジャンル**: アクション
- **制作日**: 2026-11-26
- **操作**: WASD / 矢印キー、スマホはドラッグ

## テーマ・狙い
60秒で野原の草を刈りまくるゲーム。爽快感・達成感の調査で得た知見（即時フィードバック、痕跡、完了音）を反映した改修版。
プロジェクトのコンセプトは「5歳児でも遊べるゲームを100つくる」（2026-11-26に変更）。

## 学んだこと
- フィールドを12区画に分け、区画を刈り切るたびに完了音（DING）とボーナスで「小さな完了の連鎖」を作る
- 刈った痕跡のコントラスト（濃い緑→明るい黄緑）を最大化すると達成感が跳ね上がる
- コンボで効果音の音階が上がる増幅、芝刈り機の成長、制限時間なしののんびりモード

## 反省・次にやりたいこと
- 5歳児でも遊べるという新コンセプトに合わせ、操作や難しさの見直しは今後の課題
- このゲームは単一HTMLファイル構成で、共通モジュール（shared/）にはまだ切り出していない

## 5歳児向け改良（2026-11-26、子ども向けゲーム調査に基づく）
- 標準モードを制限時間なしに変更（60秒は任意モードとして残置）。失敗・罰なしは維持
- 区画完了ごとに、完了区画数と刈った本数を大きな数字で数え上げる演出を追加（数への関心への接続）
- スタート画面はアニメーションで遊び方を見せる絵中心の案内にし、ボタンを大型化
- 約7秒無操作で近くの未刈りエリアが光る足場かけヒント、過程を褒める表示と星・花のごほうび演出を追加
