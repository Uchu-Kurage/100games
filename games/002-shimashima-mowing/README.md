# 002 しましま草刈り

- **ジャンル**: アクション（作業系・のんびり）
- **制作日**: 2026-11-26
- **操作**: ドラッグした方向へ進む（スマホ・マウス）／ WASD・矢印キー。P で一時停止、M で音のオン・オフ

## テーマ・狙い
快感の核は「通った跡の草が一気に消えて、しましまの芝生が残っていく」こと。
001 が「60秒で刈りまくる」スコアアタックだったのに対し、002 は game-feel スキルの指針どおり
**制限時間なし・作業の気持ちよさだけを残す**（PowerWash 型）方向で作った。

| 要素 | 入れたもの |
|---|---|
| 1 即時フィードバック | 刈った同フレームに草が消え、刈り音（ノイズのピッチを毎回ゆらす）と破片が出る。エンジン音が速度・負荷で変わる |
| 2 痕跡 | 刈った**向き**で芝の色が4種類に変わり、本物の芝生のような縞模様が残る。飛んだ刈り草は地面に焼き付いて消えない |
| 3 小さな完了の連鎖 | 庭を区画に分け、100% になった瞬間だけチャイム＋小さなヒットストップ＋光。97% で取りこぼしを波紋状に自動で一掃してから鳴らす |
| 4 入力に対する出力 | ステージごとに草刈り機が成長（手押し → エンジン → 乗用 → トラクター、刈り幅 13 → 31px） |
| 5 課題と技能 | 時間ではなく「縞のきれいさ」（隣り合うマスの向きのそろい具合）とタイムの自己ベストで手応えを作る |
| 6 自分のペース | 制限時間・失敗なし。障害物にぶつかっても軽く跳ね返るだけ。順序は自由で、今いる区画を点線で薄く示す |
| 7 成長の可視化 | クリア画面でビフォー／アフターを並べ、次の草刈り機の刈り幅を予告する |

## 学んだこと
- 地面を「8px マス × 80×48」の格子で持ち、別 canvas に描いておいて**刈ったマスだけ描き直す**と、草の葉を何千本描いても軽い。葉が上のマスにはみ出すので、上のマスも一緒に描き直す必要がある
- 「刈った向きで色を変える」だけで、まっすぐ往復したくなる＝自然に美しさの目標が生まれた
- 区画の最後の数マスを探す作業は気持ちよくないので、97% で自動一掃 → 100% の瞬間にチャイム、にした（99% では鳴らさない）
- 抵抗 → 解放：草の中では少し遅くなり、エンジン音も下がる。刈り終えた場所に出ると速くなる
- コンボは「止まって1秒」で静かに戻るだけ。ノルマにしない

## 反省・次にやりたいこと
- 音量・抵抗の強さ・コンボの上がり方は、実機で遊んで詰めたい
- 縞の「きれいさ」の計算は単純（隣のマスと向きが同じ割合）。往復の幅がそろっているかも見たい
- チャレンジモード（制限時間あり）は本編と分けて入れる余地がある
