# 002 たこやき

- **ジャンル**: 反射・タップ
- **制作日**: 2026-11-26
- **操作**: クリック / タップ、キーボード 1〜9

## テーマ・狙い
3×3の穴から出るモグラを60秒でたたくゲーム。爽快感調査のP0（即時フィードバック＋痕跡＋小さな完了＋確定音）を1匹ごとに試す設計。
プロジェクトのコンセプトは「5歳児でも遊べるゲームを100つくる」（2026-11-26に変更）。タップだけでも遊べるので新コンセプトと相性が良い。

## 学んだこと
- たたいた瞬間にポップ音＋星の破片＋穴に星マークの痕跡を残す即時フィードバック
- 完了音（DING）は10匹ごとの区切りでだけ鳴らし、毎回の音と差をつける
- コンボで倍率（最大×5）と音のピッチを上げる増幅。切れても罰なし
- 30秒でハンマーが大きくなり、隣の穴まで巻き込める「成長」の入れ方
- 爆弾モグラは入れず、金のモグラ（50点・短時間出現）だけでリスクとリターンを作る

## 反省・次にやりたいこと
- 60秒後の結果画面や金のモグラ、ハンマー成長は自動チェックでは未到達で、コード確認のみ。実際に遊んだ感想で調整したい
- このゲームは単一HTMLファイル構成で、共通モジュール（shared/）にはまだ切り出していない

## 5歳児向け改良（2026-11-26、子ども向けゲーム調査に基づく）
- 標準モードを制限時間なしに変更（終わりは「おしまいにする」で自分で決める。60秒は任意モードとして残置）
- 「叩く→集める」に表現を置換: ハンマーを虫取り網に替え、つかまえたモグラは笑顔でカゴへ集まる
- 集めた数を大きな数字で数え上げ、カゴにモグラが増える表示を追加
- 約7秒無操作でモグラが揺れて光る足場かけヒント、過程を褒める表示とごほうび演出を追加。逃がしても罰なし
- 出現は少しゆっくり・同時最大2匹に調整

## タイムアタック化と表示の整理（2026-11-26、実プレイのフィードバック）
- 標準モードを「50匹タイムアタック」に変更: カウントアップタイマー、50匹で終了しクリアタイムを表示（ベストタイムはセッション内保持）。時間なしモードは任意で残し、60秒モードは整理
- 見づらさ対策: 穴に残る花の痕跡を小さく・0.7秒で消える形にし、星・花の盤面散布と浮き文字を廃止
- 称賛や数字のポップを盤面に重ねず、盤面の外の表示とカウンター更新に移し、タップを妨げないようにした

## レイアウト安定化（2026-11-26、実プレイのフィードバック）
- 上部情報エリア（HUD・称賛ライン・進捗・カゴ表示）をすべて固定高さ化し、プレイ中に盤面の位置が動かないようにした
- 主因は2つ: 称賛ラインが空のときに高さが潰れていたこと、カゴのモグラが増えると折り返して領域が伸びていたこと。カゴ表示は最新11匹＋「あと○ひき」に変更

## ゲーム作りの工夫（2026-11-26にゲーム画面からREADMEへ移行）
※教育的観点は「保護者向け」としてゲーム画面下部に残している。ここには制作ノート（工夫）だけを置く。
- 気持ちよさの工夫（調査のP0を1匹ごとに適用）: タップした瞬間に音＋反応が返る即時フィードバック／つかまえた跡が残る痕跡／10匹ごとの小さな完了（完了音は区切りでだけ鳴らす）／れんぞくで音のピッチと倍率が上がる増幅（切れても罰なし）／金のモグラのリスクとリターン／30秒で網が大きくなる成長
- 画面の工夫: 盤面の上にメッセージを重ねない／上部情報エリアは固定高さにして盤面の位置が動かないようにする／装飾（花・星）は盤面に残さず視認性を優先
- 5歳向けの工夫: 「叩く→網で集める」表現／集めた数を大きく数え上げる／約7秒無操作でモグラが揺れて光るヒント／過程を褒める表示／出現はゆっくり・同時最大2匹（タイムアタック標準化の際に一部調整）
- 文字のルール（プロジェクト標準）: ゲーム画面の文字は最小限・ひらがなのみ（「あそぶ」「おしまい」「あつめた」等）
