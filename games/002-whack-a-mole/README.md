- **操作**: クリック / タップ、キーボード 1〜9

## テーマ・狙い
爽快感・達成感の調査で整理したP0（即時フィードバック＋痕跡＋小さな完了＋確定音）を、1匹ごとに全部試す。
1個目「草刈りゲーム」（連続・面的な快感）とは対照的な「点・瞬間」の快感を鍛える。

## 学んだこと
- たたいた瞬間にポップ音＋星の破片＋穴に星マークの痕跡を残す即時フィードバック
- 完了音（DING）は10匹ごとの区切りでだけ鳴らし、毎回の音と差をつける
- コンボで倍率（最大×5）と音のピッチを上げる増幅。切れても罰なし
- 30秒でハンマーが大きくなり、隣の穴まで巻き込める「成長」の入れ方
- 爆弾モグラは入れず、金のモグラ（50点・短時間出現）だけでリスクとリターンを作る

## 反省・次にやりたいこと
