# 002 もぐらたたき

- **ジャンル**: 反射・タップ
- **制作日**: 2026-11-26
- **操作**: クリック / タップ、キーボード 1〜9

## テーマ・狙い
3×3の穴から出るモグラを60秒でたたくゲーム。爽快感調査のP0（即時フィードバック＋痕跡＋小さな完了＋確定音）を1匹ごとに試す設計。
プロジェクトのコンセプトは「5歳児でも遊べるゲームを100つくる」（2026-11-26に変更）。タップだけでも遊べるので新コンセプトと相性が良い。

## 学んだこと
- たたいた瞬間にポップ音＋星の破片＋穴に星マークの痕跡を残す即時フィードバック
- 完了音（DING）は10匹ごとの区切りでだけ鳴らし、毎回の音と差をつける
- コンボで倍率（最大×5）と音のピッチを上げる増幅。切れても罰なし
- 30秒でハンマーが大きくなり、隣の穴まで巻き込める「成長」の入れ方
- 爆弾モグラは入れず、金のモグラ（50点・短時間出現）だけでリスクとリターンを作る

## 反省・次にやりたいこと
- 60秒後の結果画面や金のモグラ、ハンマー成長は自動チェックでは未到達で、コード確認のみ。実際に遊んだ感想で調整したい
- このゲームは単一HTMLファイル構成で、共通モジュール（shared/）にはまだ切り出していない

## 5歳児向け改良（2026-11-26、子ども向けゲーム調査に基づく）
- 標準モードを制限時間なしに変更（終わりは「おしまいにする」で自分で決める。60秒は任意モードとして残置）
- 「叩く→集める」に表現を置換: ハンマーを虫取り網に替え、つかまえたモグラは笑顔でカゴへ集まる
- 集めた数を大きな数字で数え上げ、カゴにモグラが増える表示を追加
- 約7秒無操作でモグラが揺れて光る足場かけヒント、過程を褒める表示とごほうび演出を追加。逃がしても罰なし
- 出現は少しゆっくり・同時最大2匹に調整
