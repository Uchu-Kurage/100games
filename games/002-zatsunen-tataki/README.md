# 002 雑念たたき

- **ジャンル**: 反射・タップ
- **制作日**: 2026-11-26（テーマずらし改修も同日）
- **操作**: クリック / タップ、キーボード 1〜9

## テーマ・狙い
もとは「もぐらたたき」。操作（出現した対象を素早くたたく）はそのままに、テーマだけをずらして独自性を出す実験作。
瞑想中に浮かぶ雑念を警策で払う。静けさ×たたく、の衝突が狙い。相手はあくまで自分の心の雑念で、宗教儀式そのものを笑う表現にはしていない。

## 学んだこと
- 10匹ごとの完了音DINGが、テーマ側の必然性で「鐘の音（ゴーン）」に格上げできた。完了音に意味が宿ると気持ちよさが固定される
- 雑念に吹き出しテキスト（「晩ごはん何にしよう」等16種）を持たせると、1ヒットごとの反応がテーマ固有になる
- コンボは「集中の持続」、金のモグラは「悟り」（50徳・短時間出現）、成長は「警策が大きくなって隣のマスまで届く」に読み替えた
- 痕跡は円相スタンプ、破片は花びらに
