# 003 ハンドドリップ珈琲

- **ジャンル**: シミュレーション（作業系・のんびり）
- **制作日**: 2026-11-26
- **操作**: ① ミルのまわりをぐるぐるドラッグ（Space 長押しでも可）② ③ 押しているあいだお湯を注ぐ（矢印キー＋Space でも可）。Enter できあがり、P 一時停止、M 音のオン・オフ

## テーマ・狙い
快感の核は「ハンドルを回すたびにゴリッと豆が砕け、お湯を注ぐと粉がふくらみ、ぽたぽたと珈琲が落ちていく」こと。
実際に淹れている感覚を味わってもらうため、**手の動きをそのまま道具の動きにする**（円を描く＝ハンドルを回す、押す＝ケトルを傾ける）ことを優先した。
面倒な部分（お湯を沸かす・フィルターを折る・片付け）は削り、「挽く → 蒸らす → 注ぐ」だけを残した。

| 要素 | 入れたもの |
|---|---|
| 1 即時フィードバック | 回した瞬間に「ゴリッ」（毎回ピッチをゆらす）と破片、ミルが小さく揺れる。注いだ瞬間に粉の色が濃く変わり、水音が鳴る |
| 2 痕跡 | 豆がホッパーから1粒ずつ消え、引き出しの窓に粉がたまる。湿った粉の色、サーバーにたまる珈琲 |
| 3 小さな完了の連鎖 | 挽けた → 全体が湿った → 蒸らしOK → 1〜3投目 → できあがり、のたびに確定音 |
| 4 入力に対する出力 | 少し注ぐだけで粉全体がふくらみ、泡が湧いてくる（蒸らし） |
| 5 課題と技能 | 速く回しすぎると粒がばらつく／注ぎすぎるとあふれる／縁に注ぐと薄くなる。挽き目で落ちる速さが変わる |
| 6 自分のペース | 制限時間なし。待つかどうか・いつ完成にするかはプレイヤーが決める |
| 7 成長の可視化 | 味の評価（酸味⇄苦味・香り・すっきり・量）と、挽き目ごとのベスト点、淹れた杯数 |

## 学んだこと
- 「ぐるぐる回す」は、ミルの中心からの角度の差分を毎フレーム足すだけで素直に作れる。時計回りだけを有効にし、逆回しは空回りの音だけにした
- しずくの音は、サーバーにたまるほど音程を上げると「たまっていく」感じが耳でもわかる（本物の容器と同じ現象）
- 粉が吸う量（40ml）を「湿っている面積」に比例させると、中心だけに注いでもお湯がたまって全体に広がる、という本物っぽい挙動が自然に出た
- 実際の抽出（2〜3分）は長いので、ゲーム内では約75秒を理想にして縮めた

## 反省・次にやりたいこと
- 蒸らしのふくらみ・泡の量、注ぐ速さ、あふれやすさは実機で遊んで詰めたい
- 豆の種類（焙煎度）を選べるようにすると、挽き目との組み合わせで遊びが広がりそう
- 注いだ軌跡（「の」の字のきれいさ）も評価に入れてみたい
