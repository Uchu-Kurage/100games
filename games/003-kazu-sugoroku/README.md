# 003 かずすごろく

- ジャンル: テーブル／数ボードゲーム（線形すごろく）
- 対象: 5歳前後（文字が読めなくても遊べる）
- 遊び方: 大きなサイコロをタップすると、出た目（1〜3）の数だけうさぎのコマが1マスずつ進む。スタートから数字のマス（1〜20）を数えながら進んで、ゴールを目指す。制限時間なし・後退や罰なし
- ステータス: 完成（2026-11-26）。通しプレイでゴール到達・結果表示を確認済み
- 対応する力: 数の大小・数直線・数えること（計数）・数字の識別

## ゲーム作りの工夫
※ゲーム画面には制作ノートを置かない方針のため、工夫はここに書く。教育的観点はゲーム画面下部の「保護者の方へ」に掲載している。
- 根拠の形をそのまま実装: Ramani & Siegler (2008) の実験で効果があったのは「線形（直線）のボード＋数字のマス＋1つずつ数えながら進む」組み合わせで、色だけの盤では効果がなかった。だから色分けではなく数字を主役にし、コマは必ず1マスずつ進み、止まるたびに今の数字が特大で表示され、音階も1段ずつ上がる（数え上げの可視化・可聴化）
- サイコロの目は1〜3: 5歳児が一度に数えられる範囲に絞り、数える行為そのものが遊びの中心になるようにした
- 後退・罰・制限時間なし: すごろくの定番である「ふりだしに戻る」等は入れず、前に進むだけの安心設計（プロジェクトの子ども向け設計指針に沿う）
- 小さな完了の連鎖: 1マス進むごとに数字表示と音が返り、ゴールでは紙吹雪と「振った回数分の星」で達成を見える化
- 文字のルール（プロジェクト標準）: ゲーム画面の文字は最小限・ひらがなのみ（タイトル「かずすごろく」、ボタン「はじめる」「もういちど」）。数え上げの主役は上部の特大カウンター
- レイアウト: 情報表示エリアは固定高さにして、プレイ中に盤面がずれない（もぐらたたきでの学びを最初から適用）。スマホでは20マス全てを1行に収めるためマスの数字は小さめで、大きな数字の役割は上部カウンターが担う
- 音は Web Audio API で生成（ファイル不要）。音の聞き取り確認は未実施で、コード確認のみ

## 学んだこと
- 「効果のある設計」はジャンル名ではなく中身の組み合わせ（線形＋数字＋計数）で決まる。見た目が似ていても色だけの盤では効果が消える、という実験結果をそのまま設計判断に使えた

## 二層設計の見直し（2026-11-27）
- 通常モード（子ども層）は無変更。大人層として新モード「えらべる すごろく」を追加した
- サイコロ2つのどちらで進むかを選べる＋ゴールはぴったり必須。行き過ぎる目は選べず、両方不可なら理由表示のうえ振り直し。これにより「どちらの目で進めばゴールに合うか」という戦略が生まれる
- 目標回数（パー9回）と比べて星1〜3ランク、セッション内ベスト（最少回数）を表示。数え上げ演出はこのモードでも維持
