# 004 いろ・かたち あわせ

- ジャンル: マッチング／分類パズル
- 対象: 5歳前後（文字が読めなくても遊べる）
- 遊び方: 上に大きく出る「おてほん」（色×形）と同じものを、下の大きなカード（3〜4枚）からタップして選ぶ。1セット10問、制限時間なし・罰なし
- ステータス: 完成（2026-11-26）。通しプレイで10問完了・結果表示を確認済み
- 対応する力: 色・形の認識、分類（同じ／違いを見分ける）

## ゲーム作りの工夫
※ゲーム画面には制作ノートを置かない方針のため、工夫はここに書く。教育的観点はゲーム画面下部の「保護者の方へ」に掲載している。
- 段階づけ（足場かけ）: 最初は「色だけ」「形だけ」を合わせる問題から始め、ミスなし正解が続くと「色と形の両方」の問題に進む。両方モードでは「色だけ同じ」「形だけ同じ」「両方違う」カードを混ぜて、どこが同じでどこが違うかを比べられる対比にした
- 間違いへの支援: 間違えたカードは揺れて薄くなり、選択肢がその場で絞られる（罰ではなく支援として働く）。約7秒無操作で正解がそっと金色に光るヒント
- 小さな完了の連鎖: 正解ごとに音＋星・花の演出と数え上げ、進み具合はドットで表示。10問で紙吹雪と星の数の結果表示
- 文字のルール（プロジェクト標準）: ゲーム画面の文字は最小限・ひらがなのみ（タイトル「いろ・かたち あわせ」、ボタン「はじめる」「もういちど」）
- レイアウト: おてほん周りとカウンターは固定高さにして、全問を通して選択肢の位置が動かないようにした（もぐらたたきでの学び）。選択肢は5歳児がタップしやすい大きなカード
- 音は Web Audio API で生成（ファイル不要）。音の聞き取り確認は未実施で、コード確認のみ

## 学んだこと
- 「分類」は、正解／不正解の二択ではなく「間違えたら絞られる」という支援の形にすると、罰なしのまま考える手がかりになる
- 対比（色だけ同じ／形だけ同じ）を意図的に混ぜることで、「両方を見る」こと自体がゲームの山場になる
