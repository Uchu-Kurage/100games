# 005 リズム まねっこ

- ジャンル: リズム／音楽（まねっこ・サイモン形式）
- 対象: 5歳前後（文字が読めなくても遊べる）
- 遊び方: 4つの大きな色パッド（動物の絵つき、それぞれ違う音階）が音と光で順番を鳴らすので、同じ順番にタップして真似する。全8ラウンド、制限時間なし・罰なし
- ステータス: 完成（2026-11-27）。状態遷移と間違い時の再再生は実操作で確認済み。全ラウンド完走の演出と音はコード確認のみ
- 対応する力: 聴覚的な短期記憶、模倣、順番の保持

## ゲーム作りの工夫
※ゲーム画面には制作ノートを置かない方針のため、工夫はここに書く。教育的観点はゲーム画面下部の「保護者の方へ」に掲載している。
- 段階づけ: 順番の長さは2音から始め、全8ラウンドで 2,2,3,3,4,4,5,6 と少しずつ長くする。再生速度はゆっくりめにし、ラウンドの進み具合はドット、押せた分は小さなドットで見える化
- 聞き直し自由: 「もういちど きく」ボタンでいつでも順番を聞き直せる。間違えてもゲームオーバーにせず、自動で同じ順番を再再生して再挑戦できる（罰ではなく支援）
- ヒント: 自分の番で約7秒無操作だと、次に押すパッドがそっと光る
- 音の設計: Web Audio API でペンタトニック（ドレミソラ）の音階を生成し、どの組み合わせでも不協和にならないようにした。再生中は入力をロックするなど状態管理（きく番／押す番）を明確に分けた
- 文字のルール（プロジェクト標準）: ゲーム画面の文字は最小限・ひらがなのみ（タイトル「りずむ まねっこ」、「きいてね」「おしてね」等の短い案内）
- レイアウト: 上部の表示領域は固定高さにして、全状態を通してパッドの位置が動かないようにした（実操作で位置の一致を確認済み）

## 学んだこと
- 音が主役のゲームは、検証が一番難しい（自動チェックでは音が聞けない）。状態遷移は実操作で確認できたが、完走と音の聞き取りは人の耳での確認が残る
- 「間違えたら終わり」のサイモン形式を、「間違えたら聞き直して再挑戦」に変えるだけで、記憶の遊びが罰のない形になる
