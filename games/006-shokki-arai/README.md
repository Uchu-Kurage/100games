# 006 しょっき あらい

- ジャンル: パズル（セイムゲーム式・連鎖消し）
- 対象: 5歳前後〜大人（二層設計）
- 遊び方: 6×6の盤面で、つながった同じ色3つ以上のまとまりをタップすると消え、タイルが落ちて補充される。落下で新しいまとまりができると連鎖する
- モード: 「じゆう」（制限時間なし）／「60びょう」（スコアアタック、自己ベスト・星ランクつき）
- ステータス: 完成（2026-11-27）。消去・連鎖・タイマー・結果表示は実操作で確認済み
- 対応する力: 分類・パターン認識、まとまりを数える、先を読む思考

## ゲーム作りの工夫（二層設計の初回）
※ゲーム画面には制作ノートを置かない方針のため、工夫はここに書く。教育的観点はゲーム画面下部の「保護者の方へ」に掲載している。
- 背景: ユーザーの方針変更（2026-11-27）「教育的観点もありつつ、大人でも爽快感や達成感を味わえるものにしたい」を受け、入口は5歳児のまま、大人用の層を重ねる「二層設計」を初めて採用した
- 子ども層: 入れ替え操作は使わず、まとまりをタップするだけ。各色に固有の形（あか=まる、あお=しかく、きいろ=ほし、みどり=さんかく）を対応させ、色と形の二重手がかりにした（いろ・かたち あわせの発展、色覚への配慮も兼ねる）
- 大人層の核は連鎖と増幅: 連鎖数で得点倍率と音程が上がり、演出も大きくなる。大きなまとまりほど得点が二乗で伸びるため、「今消すか、育ててから消すか」というリスクとリターンが生まれる（爽快感調査の「リスクとリターンの近接」「増幅」）
- 上達の可視化: 60びょうモードにセッション内ベストと星ランク。失敗しても倍率が戻るだけで罰はない、という子ども向けの優しさとの両立を狙った
- 実装上の学び: 連鎖は「落下で新たにできたまとまり」だけを対象にしないと、盤面の既存のまとまりまで巻き込んで暴走する。監査で最大5連鎖まで発生して安定することを確認済み
- 文字のルール（プロジェクト標準）: ゲーム画面の文字は最小限・ひらがなのみ（タイトル「ならべて けす」、ランクは星の数で表現）
- レイアウト: スコア表示は固定高さHUDに常時表示し、盤面の位置が動かないようにした

## 学んだこと
- 「子どもには失敗がない、大人には攻める理由がある」は矛盾しない。罰ではなく「倍率とベスト」という前向きな仕掛けで両立できる
- 連鎖の気持ちよさは、連鎖の定義（何を連鎖と数えるか）の設計で決まる
