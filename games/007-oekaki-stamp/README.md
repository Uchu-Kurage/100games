# 007 おえかき スタンプ

5歳児でも遊べるゲームを100つくる — 7個目。
ジャンル: サンドボックス／創作（ジャンル×教育の対応表で◎）。

## あそびかた
- スタンプ（たいよう・おはな・ほし・さかな・くるま・りんご・とり・おうち の8種類）から選んで、キャンバスをタップすると「ポン」という音と弾むアニメーションで押せる。押すたびに数が大きく数え上がる
- 「おだい」モード：お題（おはなばたけ／おべんとう／おうち／うみ／おまち の5種類）が1つずつ出て、必要なスタンプが絵＋大きな数字＋丸印で示される。そろうとチェックが付き、「できた」ボタンで紙吹雪＋作品の拡大表示でお祝い
- 「じゆうに かく」モード：お題なしで自由に押せる
- 「ひとつ もどす」「ぜんぶ けす」あり。制限時間なし・罰なし

## 二層設計（子ども層＋大人層）
- 子ども層：勝ち負けのない自由な創作。お題は「作り切った感」を補うための緩いゴールとして置く
- 大人層：お題の完成タイムと、必要以外の余分なスタンプ数で星ランク判定。お題ごとの最速タイムは localStorage（oekaki-stamp-best-v1）に保存され、保存できない環境ではセッション内ベストとして動作する。素早く連続で押すと音程が上がるコンボ音で、押す行為自体の気持ちよさも重ねた

## ゲーム作りの工夫
- サンドボックスの弱点「作り切った感がない」への答えとして、お題カード方式を採用。必要なスタンプと数を絵＋大きな数字で示し、達成の瞬間（全部そろう→「できた」）を明確にした
- スタンプを押すたびに数が大きく数え上がることで、創作しながら自然に数に触れる（保護者向けセクションに教育的観点を記載）
- 約7秒無操作で、次に必要なスタンプがパレットで光るヒント（自由モードでは光らない）
- 上部エリアは固定高さで、数が増えてもキャンバスの位置が動かない
- ゲーム画面の文字は最小限・ひらがなのみ。教育的観点は「保護者の方へ」として画面下部に残し、作りの工夫はこのREADMEに置く
- モチーフは「日常の動作」：スタンプを押すという現実の動作そのものの気持ちよさ（押す感触・跡が残る・作品が残る）を核にした

## 検証メモ
- 実操作プローブで一通り確認：お題1を実際に押して全チェック点灯→「できた」有効化→お祝い表示（星3・タイム・紙吹雪・作品拡大）→次のお題への移行、もどす／けす、自由モード
- 「できた」ボタンの鼓動アニメーション（transform）がプローブのクリック判定と干渉したため、影の明滅だけのアニメーションに変更して解消
- 音（スタンプ音・ファンファーレ・コンボ音程）と7秒ヒントの発光はコード確認のみ。ベスト保存は書き込み経路を確認、再読み込み後の復元はコード実装済みだがプローブ環境では未検証
