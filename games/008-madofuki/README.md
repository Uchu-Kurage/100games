# 008 まどふき

5歳児でも遊べるゲームを100つくる — 8個目。
ジャンル: おそうじ／なぞり（モチーフは日常の動作「ふく」）。

## あそびかた
- くもった窓を指でなぞると、くもりが拭き取れて下の景色（さくら・うみ・ゆき・にじ の4場面）が見えてくる
- 拭いた割合が上部に大きく表示される。95%以上拭けたら完成で、紙吹雪＋ファンファーレ＋景色が明るくなるお祝い。「つぎの まど」で次の場面へ
- 制限時間なし・罰なし。約7秒無操作で、拭き残しがうっすら光るヒント

## 二層設計（子ども層＋大人層）
- 子ども層：なぞるだけで景色が現れる「汚れ→きれいの痕跡」が核。割合表示で「あと少し」が目で分かる
- 大人層：完成時に時間と拭き残しの少なさで星ランク。「60びょう」モードは拭き切った枚数＋拭いた割合の合計を競うスコアアタック（星ランクつき）。最速タイムと最高スコアは localStorage（madofuki-best-v1）に保存され、保存できない環境ではセッション内ベストとして動作する

## ゲーム作りの工夫
- 景色レイヤーの上にくもりレイヤー（Canvas）を重ね、なぞった軌跡を destination-out で消去して景色を見せる。拭いた割合はサンプリングで定期計算し、95%を完成ラインにした（四隅などの拭き残しで詰まらないライン設定）
- 拭く速さで少し音程が上がる「キュッ」という拭き音（Web Audio）で、操作と音を結びつけた
- 上部エリアは固定高さで、割合が変わっても窓の位置が動かない
- ゲーム画面の文字は最小限・ひらがなのみ（数字と%は大きく）。教育的観点は「保護者の方へ」として画面下部に残し、作りの工夫はこのREADMEに置く
- モチーフ基準（日常の動作・操作の動詞と一致・痕跡がある）に最も素直にハマる題材として「窓ふき」を選んだ。草刈りと同じ「面倒だけど終わると気持ちいい家事」の系譜

## 検証メモ
- 監査パス（コンソールエラーなし、横はみ出しなし）。モード切替ボタンの応答は実操作で確認
- なぞって拭く操作そのもの・完成時のお祝い・ヒント発光・音は、プローブにドラッグ操作の手段がないためコード確認のみ（消去・割合計算・完成判定の実装は確認済み）。実プレイでの確認はユーザーに依頼する
