# 009 さがしもの

5歳児でも遊べるゲームを100つくる — 9個目。
ジャンル: 探し絵（モチーフは日常の「なくし物を探す」、動詞は「さがす」）。

## あそびかた
- 場面は4つ（リビング、キッチン、こどもべや、げんかん）。各場面に日常のなくし物（かぎ、くつした、リモコン、めがね、さいふ、ぼうし等）が3つ隠れている
- 上部の固定エリアに探す物の絵が大きく並ぶ（文字なし）。見つけてタップすると音と光の演出で、上部の絵にチェックが付く
- 3つ全部見つけたら紙吹雪＋ファンファーレで場面クリア。制限時間なし・罰なし（ミスタップは小さな音だけ）。約7秒無操作で、見つかっていない物がうっすら光るヒント

## 二層設計（子ども層＋大人層）
- 子ども層：絵と音だけで進む探し絵。隠し方は「同化しすぎず、一目では分からない」程度に調整し、当たり判定は少し大きめ
- 大人層：全場面の合計タイムとミスタップ数で星ランク。上級モード「むずかしい」は探す物が5つに増え、物が小さく背景になじむ。ベストタイムは通常・上級で分けて localStorage（sagashimono-best-v1）に保存し、保存できない環境ではセッション内ベストとして動作する

## ゲーム作りの工夫
- 探す物はすべて「家の中で本当になくす物」に統一し、モチーフ（日常の探し物）と遊びの動詞（さがす）を一致させた
- 場面の絵はすべて自作SVG。物は家具や小物と色味を近づけて同化させつつ、輪郭は残して理不尽な難しさにしない
- 上部エリアは固定高さで、チェックが増えても場面の位置が動かない
- ゲーム画面の文字は最小限・ひらがなのみ。教育的観点は「保護者の方へ」として画面下部に残し、作りの工夫はこのREADMEに置く

## 検証メモ
- 実操作プローブで通常モード4場面の全クリア、結果表示（星・ミス回数・新記録・ベスト引き継ぎ）、再開導線まで確認。上級モードの5つ表示とレイアウトも確認
- 検証中に見つけた不具合2件（結果カードがスマホではみ出してボタンが押せない、上級モードで上部の数表示が切れる）は、結果・スタート画面のモーダル化とスロット縮小で修正済み
- 音の聞こえ、7秒ヒントの発光、経過時間の実数値は監査環境の制約で未確認（配線はコード確認済み）
