# 010 ドミノ たおし

5歳児でも遊べるゲームを100つくる — 10個目。
ジャンル: 連鎖／しかけづくり（モチーフは「ならべて たおす」）。

## あそびかた
- 盤を指でなぞると、その線にそってドミノが並ぶ（色は並べた順に虹色）
- 「たおす！」ボタン、または立っているドミノをタップすると、そこから連鎖して倒れていく
- ステージ（6つ）はドミノの列をベルまでつなげて、ベルを全部鳴らすとクリア。分かれ道・回り道・障害物（本）が順に増える
- 「じゆう」はベルなしで好きなだけ並べて倒す。一度に倒した枚数が20枚以上だとお祝い
- 失敗しても「たてなおす」で並べたドミノがそのまま立ち直る。「ひとつ もどす」で最後の線だけ消せる。制限時間なし

## 二層設計（子ども層＋大人層）
- 子ども層：なぞる → 押す → 一気に倒れる、の3ステップだけ。同じ線の中は急カーブでも必ず最後まで倒れ、ベルはそばを通るだけでも鳴る（やさしい判定）
- 大人層：星3つ＝「ベルを全部鳴らす」「1回押すだけで全部鳴らす」「目安の枚数以下」。目安はスタートからベルを順にたどった距離から自動計算。ステージごとの星と最少枚数、「じゆう」の一度に倒した最高枚数を localStorage（domino-best-v1）に保存し、保存できない環境ではセッション内ベストとして動作する

## ゲーム作りの工夫（game-feel の7要素）
- **快感の核**：「自分で並べたドミノが、指1回で端まで倒れきる」。準備（並べる）と解放（倒す）をはっきり分けた
- **即時フィードバック**：並べるたびにポップインと「コトッ」（線の中で少しずつ音が上がる）。倒れるたびに「カチ」と、上の大きな数字がはねる
- **入力に対する出力の大きさ**：1タップで数十〜数百枚が倒れる。連鎖が長いほど少しずつ速くなる
- **音の音楽化**：倒れる音をペンタトニックで上り下りさせ、連鎖そのものがメロディになる
- **痕跡**：倒れたドミノは寄りかかったまま残り、虹色の道が「自分の仕事の跡」になる
- **小さな完了**：ベル1つごとに「チーン」＋ヒットストップ（0.09秒）＋小さな画面シェイク＋光の粒。全部鳴ったらファンファーレと紙吹雪。10枚ごとに数字が大きくはねる
- **失敗の軽さ**：「たてなおす」は並べた形を保ったまま、順番にポンポン立ち直る演出つき
- **自分のペース**：ステージはどれからでも選べる。ヒント（ベルへの点線、押す場所の丸）は数秒操作がないときだけ出る
- ドミノの見た目は、倒れる角度に合わせて箱の8頂点を計算し、見える面だけを陰影つきで描く疑似3D（Canvas 2D）。影は頂点を地面に落とした凸包

## 遊びながら直したこと
- 最初は物理的な位置関係だけで連鎖させていたが、急カーブ・分かれ道・線の横を通るベルで止まりやすかった。5歳児の描く線は角ばるので、
  - 同じ線の中で隣り合うドミノは必ずつながる
  - 既存の列の近くから描き始めた線／列に向かって描き終えた線はつながる
  - ベルはすぐ横を通るだけでも鳴る
  の3つを足した。障害物でとぎれた所はつながらないので、回り道を考える遊びは残る
- 連鎖が遅く感じたので倒れる速さを上げた（約11〜15枚／秒）
